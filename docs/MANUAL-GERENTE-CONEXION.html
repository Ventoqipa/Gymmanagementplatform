Guía práctica para el gerente o responsable del gimnasio. Explica, en orden, cómo dejar listos los lectores de acceso y comenzar a operar Elite día a día.

Sitio: https://elitegym247.tanosi.com.mx/
Público: Gerencia / recepción · Sin conocimientos técnicos avanzados
Versión: acceso ADMS directo (sin XCore)

1. ¿Qué es la plataforma?

Elite es el sistema web del gimnasio para socios, Face ID, accesos y operación diaria. Los lectores de rostro (SpeedFace) abren el torniquete y envían cada visita a Elite.

Lo que usted usa
  • Sitio Elite en el navegador
  • Menú Panel para ver si hay conexión
  • Control de acceso para visitas y Face ID
  • Miembros e Inicio para operación
Lo que debe estar listo
  • PC de recepción encendido
  • Programa Access Gateway activo
  • Lectores apuntando a ese PC
  • XCore / software viejo apagado

2. Orden de conexión (importante)

Siga estos pasos en este orden. Si se salta el cierre de XCore, el sistema nuevo no podrá arrancar.

  1. Publicar Elite El equipo técnico sube el sitio a internet. Usted solo confirma que al abrir https://elitegym247.tanosi.com.mx/ aparece el menú Panel.
  2. Desconectar XCore Cierre XCore / Panel ZKTeco y cualquier programa viejo de acceso. No deben quedar activos: solo puede haber un servidor de lectores.
  3. Activar Access Gateway En el PC del gym, ejecute una vez install-autostart.bat (o start-gateway.bat para una prueba).
  4. Configurar lectores En cada SpeedFace, servidor = IP del PC del gym, puerto = 8096.
  5. Reconectar en Elite En ese mismo PC: login → Panel → Reconectar → debe decir Conectado.
  6. Empezar a usar Alta de socios, Face ID, monitoreo de accesos y operación diaria.
Atención: XCore y el Access Gateway nuevo no pueden estar encendidos al mismo tiempo. Si el Gateway dice “puerto ocupado”, vuelva al paso 2.

3. Conectar por primera vez (en el PC del gym)

A. Cerrar el sistema anterior (XCore)

  • Cierre la ventana de XCore / Panel ZKTeco.
  • Si Windows lo abre solo al encender, quítelo del inicio automático.
  • Confirme que ningún programa viejo de acceso sigue abierto.

B. Activar el Access Gateway

  1. Abra la carpeta access-gateway en el PC de recepción.
  2. Ejecute install-autostart.bat una sola vez (si Windows lo pide, acepte como administrador).
  3. Compruebe en el navegador: http://127.0.0.1:8787/health — debe verse algo con ok.
Con el arranque automático, no hace falta abrir un archivo .bat cada mañana. Al iniciar sesión en Windows, el Gateway debería levantarse solo.

C. Configurar cada lector SpeedFace

Campo en el lectorValor
Servidor / Cloud / ADMSIP del PC del gym (ejemplo: 192.168.1.22)
Puerto8096

Entrada principal y entrada lateral deben apuntar a la misma IP del PC.

D. Conectar Elite

  1. En ese mismo PC, abra https://elitegym247.tanosi.com.mx/ e inicie sesión.
  2. Menú izquierdo → Panel.
  3. Pulse Reconectar.
  4. Debe verse Conectado y los lectores en verde (o con señal).

4. Empezar a usar la plataforma (día a día)

Cada mañana (o al abrir el turno)

  1. Encienda el PC de recepción (el Gateway debería arrancar solo).
  2. Abra Elite e inicie sesión.
  3. Vaya a Panel: si no dice Conectado, pulse Reconectar.
  4. Revise que los lectores estén conectados.

Alta de un socio nuevo

  1. Miembros → Nuevo miembro.
  2. Complete datos y cobro / membresía.
  3. En Face ID: elija el lector, pulse registrar y pida al socio que mire de frente al SpeedFace.
  4. Espere la confirmación en pantalla.

Ver quién entra

Abra Control de acceso. Ahí verá el monitor en vivo con visitas reales (no simuladas). También puede enrolar un rostro si el socio ya estaba dado de alta sin Face ID.

6. Si algo no funciona

Puerto 8096 ocupado XCore u otro programa sigue abierto → ciérrelo y vuelva a activar el Gateway.
